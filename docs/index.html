Get started with Home Assistant on a PC

Home Assistant is a free, open-source hub for your smart home. It runs on hardware you own, keeps your data in your house, and keeps working when the internet does not.

This page covers one thing: putting Home Assistant OS on an x86-64 PC. There are two ways to do it — the method Home Assistant documents itself, and a guided USB installer from this project. Both end in the same place. Using a Raspberry Pi or another board? Those have their own images; see the official installation page.

Both routes erase a disk, completely. The drive you install onto is wiped and everything on it is gone. Use a dedicated machine with nothing worth keeping, and back up anything you still need before you start.

What you need

  • A dedicated x86-64 PC (Intel or AMD) that can boot in UEFI mode. It becomes your Home Assistant machine.
  • 2 GB of RAM or more — 4 GB if you plan to run apps or cameras.
  • A drive for Home Assistant, 32 GB or more: an SSD is the usual choice. The boot drive should use 512-byte logical sectors; some NVMe drives with native 4K sectors cannot boot Home Assistant OS.
  • An Ethernet cable and internet. The first start expects a cable; Wi-Fi can be set up later.
  • A USB stick: 1 GB for the installer below, 8 GB or more for the standard route.
  • Access to the BIOS, to switch UEFI on and Secure Boot off.

The two ways

Officially supported

The standard way

Home Assistant's own guide: boot a live Ubuntu, then write the image with the Disks utility.

  1. Enter the BIOS (usually F2, Del or F10), make sure UEFI boot is on and turn Secure Boot off.
  2. Write an Ubuntu Desktop ISO to an 8 GB USB stick, boot it, and choose Try Ubuntu — do not install it.
  3. On the live desktop, connect to the network and download the image for generic x86-64 from the Home Assistant OS releases. The file looks like haos_generic-x86_64-<version>.img.xz.
  4. Open Disks, select the internal drive, open the menu and choose Restore Disk Image…, pick the file, then Start Restoring.
  5. Shut the PC down, unplug the Ubuntu stick, and start it again. Home Assistant OS is now on the drive.

Home Assistant OS has no installer of its own. A second official method writes the image from another computer with Etcher and a SATA or USB adapter — the official guide describes both.

Independent project

The guided installer

This project: one ISO that asks a few questions and writes the current Home Assistant OS for you.

  1. Download the haos-isoinstall-*-amd64.iso from Releases and check it against the .sha256 file next to it.
  2. Write the ISO to a USB stick with Etcher or Rufus — not by copying the file onto the stick.
  3. In the BIOS, turn Secure Boot off and set SATA to AHCI.
  4. Boot the stick and answer the wizard: language (14 available), network (Ethernet or Wi-Fi), and which disk to install on.
  5. It downloads the current Home Assistant OS image, verifies it and writes it. Reboot and remove the stick.

The ISO is about 450 MB because it does not contain Home Assistant OS: the image is fetched during the installation, so you always get the version that is current that day.

First boot, same for both

Once the disk is written and the stick removed, start the PC. From here on, the two routes are identical.

  1. In a browser on your network, open http://homeassistant.local/. If that does not answer, try http://homeassistant.local:8123/, or the PC's IP address with :8123.
  2. Wait for Preparing Home Assistant. This downloads the latest version and can take 20 minutes or more. It is not stuck.
  3. Choose Create my smart home and set a name, a username (lowercase, no spaces) and a password. This is the owner account, and there is no way to recover it — store it somewhere safe.
  4. Set your home location, decide what you want to share, and finish. You are in Home Assistant.
  5. From there: Settings → Devices & services to add your devices, and Settings → Apps to install extras.

If something goes wrong

The PC shows nothing after boot
Check that UEFI boot is on and Secure Boot is off, and that the written drive is first in the boot order. A drive with native 4K sectors cannot boot Home Assistant OS, whatever route you took.
homeassistant.local does not open
Multicast DNS is blocked on some networks. Find the PC's address in your router and open http://<address>:8123 instead.
It has said "Preparing Home Assistant" for a long time
Normal on a slow connection or an old drive. It downloads the current version on first start. Give it 30 minutes before you worry.
The wizard cannot find my disk
Some controllers need AHCI instead of RAID or Intel RST in the BIOS. Change the SATA mode, then boot the stick again.
Something is wrong with Home Assistant itself
Ask the Home Assistant community. This project only puts the operating system on the disk; it has no support for Home Assistant's own behaviour.
